# Job Application & Job Market Analytics

## 📌 Project Overview
A data analytics portfolio project focused on exploring and analyzing job application trends and job market dynamics. This project tracks data end-to-end: from raw data extraction, cleaning, and SQL transformations to exploratory data analysis (EDA) in Python and dashboard reporting.

---

## 📁 Repository Structure

```text
job-market-analytics/
├── data/
│   ├── raw/             # Original, immutable datasets
│   └── processed/       # Cleaned, transformed datasets ready for analysis
├── sql/                 # SQL queries, schemas, and transformations
├── notebooks/           # Jupyter notebooks for exploratory data analysis (EDA)
├── dashboard/           # BI dashboard assets, exports, and design mockups
├── images/              # Visualizations, charts, and portfolio screenshots
├── .gitignore           # Specifies files ignored by Git version control
└── README.md            # Project documentation and summary
```
